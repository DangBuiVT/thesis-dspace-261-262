# Test Case: TC06 - Cấu hình Admin: Chọn kiểu không chữ ký số (Invisible / Không hiển thị)

## 1. Mục tiêu kiểm thử (Objective)
Kiểm tra Admin có thể chọn tùy chọn ký số vô hình, không in vết chữ ký lên bề mặt tài liệu.

## 2. Tiền điều kiện (Preconditions)
Đăng nhập tài khoản Admin, mở tab Quản trị Bộ sưu tập.

## 3. Các bước thực hiện (Test Steps)
1. Tại mục 'Cấu hình Kiểu Hiển Thị Chữ Ký Số', chọn tùy chọn 'Không chữ ký số (Vô hình)'.
2. Quan sát khung xem trước.
3. Nhấn 'Lưu cấu hình'.

## 4. Kết quả mong đợi (Expected Result)
Khung xem trước hiển thị trang tài liệu sạch sẽ, không có dải con dấu; thông báo lưu cấu hình thành công.

## 5. Trạng thái kiểm thử (Status)
- **Mức độ ưu tiên:** High
- **Phân loại:** Functional / E-Signature Test
- **Người thực hiện:** Nguyễn Trần Hữu Đức
- **Kết quả:** Pass
