# Test Case: TC05 - Cấu hình Admin: Chọn kiểu chữ ký số chéo (Diagonal Ribbon)

## 1. Mục tiêu kiểm thử (Objective)
Kiểm tra Admin có thể chọn tùy chọn hiển thị chữ ký số chạy chéo góc qua trang.

## 2. Tiền điều kiện (Preconditions)
Đăng nhập tài khoản Admin, mở tab Quản trị Bộ sưu tập.

## 3. Các bước thực hiện (Test Steps)
1. Tại mục 'Cấu hình Kiểu Hiển Thị Chữ Ký Số', chọn tùy chọn 'Chữ ký số chéo trang'.
2. Quan sát khung xem trước (Live Preview).
3. Nhấn 'Lưu cấu hình'.

## 4. Kết quả mong đợi (Expected Result)
Khung xem trước hiển thị dòng chữ ký nghiêng chéo góc 45 độ ở trung tâm trang; cấu hình được lưu thành công.

## 5. Trạng thái kiểm thử (Status)
- **Mức độ ưu tiên:** High
- **Phân loại:** Functional / E-Signature Test
- **Người thực hiện:** Nguyễn Trần Hữu Đức
- **Kết quả:** Pass
