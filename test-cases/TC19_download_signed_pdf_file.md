# Test Case: TC19 - Kiểm tra tải xuống file PDF đã ký số hoàn chỉnh

## 1. Mục tiêu kiểm thử (Objective)
Xác nhận người dùng có thể tải về file PDF đã ký số với đúng tùy chọn hiển thị con dấu.

## 2. Tiền điều kiện (Preconditions)
Tài liệu đã ở trạng thái đã xuất bản (archived).

## 3. Các bước thực hiện (Test Steps)
1. Mở xem chi tiết luận văn đã lưu chiểu.
2. Nhấn nút 'Tải file đã ký số' (Download Signed PDF).
3. Mở file vừa tải về bằng trình duyệt hoặc ứng dụng đọc PDF.

## 4. Kết quả mong đợi (Expected Result)
File tải về thành công, mở bình thường và hiển thị đầy đủ các con dấu ký số đã cấu hình.

## 5. Trạng thái kiểm thử (Status)
- **Mức độ ưu tiên:** High
- **Phân loại:** Functional / E-Signature Test
- **Người thực hiện:** Nguyễn Trần Hữu Đức
- **Kết quả:** Pass
