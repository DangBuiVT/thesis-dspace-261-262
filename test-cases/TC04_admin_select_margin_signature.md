# Test Case: TC04 - Cấu hình Admin: Chọn kiểu chữ ký số 2 bên lề (Margin Strips)

## 1. Mục tiêu kiểm thử (Objective)
Kiểm tra Admin có thể chọn tùy chọn hiển thị chữ ký số chạy dọc 2 bên lề trang.

## 2. Tiền điều kiện (Preconditions)
Đăng nhập tài khoản Admin, mở tab Quản trị Bộ sưu tập.

## 3. Các bước thực hiện (Test Steps)
1. Tại mục 'Cấu hình Kiểu Hiển Thị Chữ Ký Số', chọn tùy chọn 'Chữ ký số 2 bên lề'.
2. Quan sát khung xem trước (Live Preview).
3. Nhấn 'Lưu cấu hình'.

## 4. Kết quả mong đợi (Expected Result)
Khung xem trước hiển thị dải chữ ký chạy dọc 2 bên mép lề trang; hệ thống thông báo cập nhật cấu hình thành công.

## 5. Trạng thái kiểm thử (Status)
- **Mức độ ưu tiên:** High
- **Phân loại:** Functional / E-Signature Test
- **Người thực hiện:** Nguyễn Trần Hữu Đức
- **Kết quả:** Pass
